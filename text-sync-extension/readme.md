# text sync

минимальное расширение: сохраняет текст из полей на одной странице и вставляет на другой.

## установка (chrome / edge / brave)

1. откройте `chrome://extensions`
2. включите «режим разработчика»
3. «загрузить распакованное» → выберите папку `text-sync-extension`

## как пользоваться

1. на странице, где уже заполнили форму — откройте иконку расширения → **сохранить с этой страницы**
2. перейдите на другую страницу с похожими полями
3. снова откройте popup → **вставить на эту страницу**

расширение сопоставляет поля по `id`, `name`, подписи, placeholder и порядку на странице.
